LIVE INTERACTIVE DEMO Kansas City, MO • Civic Transit Telemetry

KC Streetcar Executive Observability Dashboard

In high-availability operations—whether supporting 3,600+ retail stores from Plano or monitoring a metropolitan transit corridor in Kansas City—raw data is rarely the bottleneck; signal-to-noise ratio is. This dashboard demonstrates how to unify real-time streaming telemetry (modeled on GTFS-Realtime feeds) with historical demand baselines into a single-pane-of-glass executive view.

  • Real-Time SLA & Anomaly Detection: Polls fleet state on a 3-second interval to track rolling On-Time Performance (OTP), automatically triggering incident alerts when route variances breach SLA thresholds.
  • Historical Baseline Context (431k+ Riders): Pairs live vehicle occupancy and schedule adherence against a 12-week historical ridership curve—enabling operators to distinguish normal seasonal load from degraded capacity.
  • De-Siloed Operational Clarity: Built with Next.js, TypeScript, Tailwind CSS, and Recharts, featuring dynamic fleet health thresholds (Cars #801–#806) and embedded contextual definitions so L1–L3 engineers and executives share a unified view of system health.
